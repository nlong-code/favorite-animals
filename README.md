# My Favorite Animals

This is a React app I built for class that displays a collection of my favorite animals, along with their photos and specialties.

## What It Does
* Shows animal cards with their name, type, specialty, and picture
* Lets you filter the list by animal type or view all of them together
* Includes a search bar to look up animals by name or type

## Built With
* React and Vite
* JavaScript
* CSS and Bootstrap
